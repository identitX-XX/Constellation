# Portfolio — photos & réalisations

Dépose ici tes images (JPG/PNG/WebP), puis ajoute une entrée dans le tableau
`FOLIO` en bas de `index.html` (section « 05 · Le portfolio »), par ex. :

    { titre:"Ma série", cat:"Photographie", annee:"2026",
      img:"assets/portfolio/ma-serie.jpg",
      desc:"Deux lignes de contexte." }

Une entrée sans `img` (ou dont le fichier manque) affiche automatiquement une
vignette « constellation » de repli — la grille reste belle avant les photos.

Conseil : format ~4/3, largeur 1200–1600 px, < 400 Ko par image.
